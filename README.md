# Moses Netto — Portfolio

A fast, ATS-friendly portfolio for an **Embedded & Industrial IoT Engineer** building dependable systems from the edge to the cloud.

## Live site

[mosesnetto.github.io/portfolio](https://mosesnetto.github.io/portfolio/)

## What is included

- Recruiter-friendly hero with a clear positioning statement
- Profile portrait using the GitHub profile photo
- Industrial IoT / embedded systems positioning for jobs and startup collaborations
- Selected work from the public GitHub repositories
- Experience, education, certifications, and contact sections
- Responsive layout, semantic HTML, Open Graph metadata, and JSON-LD
- GitHub Pages deployment through GitHub Actions

## Stack

- [Astro](https://astro.build/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- TypeScript

## Local development

```bash
npm install
npm run dev
```

Build and preview the production site:

```bash
npm run build
npm run preview
```

## Customize

Edit `src/config.ts` to update the profile, projects, experience, skills, contact links, and certifications. Replace `public/moses-avatar.jpg` with a preferred portrait if needed.
